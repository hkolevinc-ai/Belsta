# BELSTA → Temu scraper

Проектът се стартира ръчно чрез GitHub Actions и създава попълнен Temu Excel файл.

## Какво прави

- Чете линковете от `input/available.xlsx`.
- При линк с `variant` ID избира цвета на този вариант и добавя всички налични размери за същия цвят.
- При линк без `variant` ID избира началния наличен цвят на продуктовата страница и добавя всички негови размери.
- Разделя всеки размер на едро на отделни размери за продажба на дребно. Например `23-27 2*26` става на пет реда: `23`, `24`, `25`, `26` и `27`.
- При повтарящи се пакетни композиции оставя само една комбинация продукт + цвят + размер и избира варианта с най-ниска цена на чифт.
- Разграничава различните реални цветове, когато първоначално се преобразуват до еднаква Temu стойност, така че да няма повторена комбинация цвят + размер.
- Изключва 15 визуално проверени изображения, които показват пакет с много чифтове, и валидира крайния файл срещу повторната им поява.
- Премахва `Опаковка:` и `на едро` от заглавието на разгънатите продукти.
- Извлича от belsta.bg заглавие, описание, характеристики, SKU, цена, зачертана цена, тегло, размер, цвят и изображения.
- Запазва структурата на предоставения Temu шаблон.
- Създава Excel файл, CSV отчет и текстово резюме.

## Заложени настройки

- Quantity: `100`
- Package dimensions: `20 × 10 × 5 cm`
- Base Price: текущата цена в belsta.bg; при опаковка цената се разделя на броя чифтове
- List Price: зачертана цена, когато е по-висока от текущата; при опаковка също се разделя на броя чифтове
- Когато няма валидна зачертана цена: `N/A`
- Всеки разгънат размер е единичен продукт: `Single set`, 1 pair, 500 g
- Handling Time: `1 Day`
- Fulfillment Channel: `I will ship this item myself`
- Country/Region of Origin: `Ukraine`
- Shipping Template: празно
- Manufacturer: празно
- EU Responsible Person: празно

## Първоначално качване в GitHub

1. Създайте ново празно repository в GitHub.
2. Разархивирайте ZIP файла.
3. Качете цялото съдържание на папката, включително `.github`.
4. Отворете раздела **Actions**.
5. Изберете **Run BELSTA Temu scraper**.
6. Натиснете **Run workflow**.
7. След приключване отворете изпълнението и изтеглете артефакта **belsta-temu-results**.

## Следващо стартиране с нов списък

Заменете `input/available.xlsx` с нов файл със същото име. Линковете трябва да бъдат в колона A, със заглавие `Link` на първия ред. След това стартирайте workflow отново.

Ако Temu предостави нов шаблон със същите категории, заменете `input/TEMU_TEMPLATE.xlsx` и проверете дали колоните и имената на листовете са останали същите.

## Резултати

- `BELSTA_TEMU_UPLOAD.xlsx` — файлът за качване в Temu.
- `BELSTA_TEMU_REPORT.csv` — преглед на включените варианти.
- `BELSTA_TEMU_SUMMARY.txt` — брой входни линкове, продукти, цветове, SKU редове и предупреждения.

## Важно

Празните Shipping Template, Manufacturer и EU Responsible Person трябва да се попълнят според настройките и регистрациите в конкретния Temu профил, ако платформата ги изисква при обработката.
